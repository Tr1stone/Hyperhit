# Hyperhit 真机测试

## 连点

1. 连接真机，Run 安装后确认无障碍服务已连接。
2. 连点页保留 500 毫秒、10 轮，显示连点悬浮控制，进入测试区。
3. 拖动控制条到不遮挡目标按钮的位置。
4. 点击“添加点”，在测试目标按钮中心按住：应显示屏幕像素 X/Y；拖动坐标更新；松开保存。
5. 点击悬浮“开始”，计数增加 10 后完成。
6. 再开始，中途暂停；当前点击结束后计数不再增长。继续后完成剩余点击。
7. 返回设置，检查位置已保存；添加第二个测试目标后验证依次执行。

## 循环滑动

1. 切到循环滑动页，确认没有重复次数输入，设置时长和间隔。
2. 显示滑动悬浮控制，进入测试区；将控制条拖离列表中准备选择的 A 起点。
3. 选 A→B，在列表内从下方 A 按住拖到上方 B，坐标应实时显示，松开保存。
4. 开始，列表持续向后滚动；到列表末尾仍保持循环运行，没有内置次数终点。
5. 点击暂停，等待当前滑动完成，列表不再发起下一次滑动。点击继续，再次从 A→B 开始。
6. 可以在自己的其他普通页面重复以上操作，验证切出 Hyperhit 后悬浮控制仍可操作。

## 生命周期和输入

- 选点时点“取消选点”，不应更改原配置；两个手指触摸也取消。
- 选点提示条遮挡目标时，可上下拖动提示条移开，再选取原位置。
- 输入空值、0 或范围外的数字，保存应提示输入问题，不能启动。
- 关闭悬浮面板后不再继续动作。
- 按住暂停而不立即松手，下一次动作也不应抢先发起；拖动悬浮控制条会先暂停任务。
- 旋转屏幕，任务结束并要求重新选点；恢复原方向也不会自动继续。
- 锁屏再解锁，任务不会自行恢复。
- 关闭再开启无障碍服务，旧悬浮面板消失，新面板能重新显示。
- 结束并重新启动 App，位置与参数仍在，任务保持未运行。

暂停不会截断已开始的手势；在最长 10 秒滑动配置下，实际进入暂停最多要等待该手势结束。
