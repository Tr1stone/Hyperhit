# Hyperhit 触摸选点与独立自动化功能

用户已确认：连点与循环滑动是两个独立功能；循环滑动没有次数限制，仅运行、暂停、继续。位置通过手指选择，按下及拖动时显示手机屏幕像素坐标。

## 操作

- 首页有“连点”和“循环滑动”两个入口，各自保存参数与位置。
- 连点：按顺序点击所选位置，可设置每次点击的间隔及循环轮数。一个位置就是单点连点，多个位置依次执行算一轮。
- 滑动：触摸按下保存 A，拖动松开保存 B；设置滑动时长及完成后等待间隔。持续重复 A→B，没有重复次数输入。
- 用户主动显示悬浮控制后，切换到目标 App，再选点或选路径。选点触摸只记录位置，不传给目标 App。
- 悬浮控制可拖动，提供选点、开始/暂停/继续、返回 App、关闭。关闭同时结束任务。
- 暂停允许正在执行的手势完成，不再排下一次；继续从完整的下一个动作开始。一次仅运行一个功能，避免系统手势互相取消。
- 位置和参数保存在手机本地。屏幕方向、尺寸改变后必须重新选点；锁屏、服务断开或系统取消手势时停止或暂停。
- 保留应用内点击计数和可滚动测试区域，便于真机验证。

## 结构

- `automation/AutomationModels.kt`：屏幕坐标、配置校验、动作计划。
- `automation/LoopController.kt`：不依赖安卓的串行运行器，处理完成、暂停、继续、过期回调。
- `AutomationStore.kt`：本地配置及可观察状态，不保存 Activity 引用。
- `overlay/AutomationOverlay.kt`：可拖动控制条、全屏触摸选点与坐标显示。
- `AutoClickService.kt`：无障碍手势、屏幕环境与运行器集成。
- `MainActivity.kt`：两个独立设置页面、状态、测试区域。

## 验证

单元测试覆盖有限连点、多点顺序、无限滑动、运行中/间隔中暂停、继续、系统取消、过期回调、非法位置。再执行 debug 编译和 lint。真机检查跨 App 选点、坐标、点击计数、滑动、暂停继续、关闭、横竖屏与锁屏。
